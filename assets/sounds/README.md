Loochies sound slots (drop your recordings here)
================================================

Place short clips with these base names. The game will pick the first
existing extension in this order: .m4a, .mp3, .ogg, .wav

- spawn: when a Loochie appears
- blocker: when a Blocker is assigned
- saved: when a Loochie reaches the EXIT
- fall: when a Loochie falls into the pit and is lost
- win: when saved >= goal and the level is won

Notes:
- If a file is missing, that event is silent (no errors).
- Keep files short and lightweight for mobile.
- Recommended: 44.1 kHz mono. iPhone Safari works well with .m4a or .mp3.
